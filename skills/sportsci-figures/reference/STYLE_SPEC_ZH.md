# 中文规范（`apply_style("zh")`）

适用：中文学位论文、开题/结题报告、国内期刊的**结果部分**。图、表、图注、表注、正文数字一律按本规范；与英文规范（`STYLE_SPEC_EN.md`）**版式、配色、统计完全相同，只有文字语言和少数排版习惯不同**。

## 1. 字体与排版
| 对象 | 规定 |
|---|---|
| 图内文字 | 拉丁字符与数字用 **Arial**，中文自动回退到 **微软雅黑**（Mac: 苹方；Linux: Noto Sans CJK SC）。`apply_style("zh")` 已配置，**不要覆盖 rcParams** |
| 图内字号 | 正文 7 pt，刻度 6.5 pt，注释 5.5–6 pt，面板字母 9 pt 粗体 |
| Word 正文 | 宋体（中文）+ Times New Roman（数字/字母）10.5 pt，行距 1.35，段首缩进 2 字符 |
| Word 标题 | 黑体：章 14 pt、节 12 pt、小节 11 pt，加粗 |
| 图注 | 图下方，8.5 pt：`图 1  标题。a，…；b，…。` 标签"图 1"黑体加粗，其后两个空格 |
| 表题 | 表上方，9.5 pt：`表 1  标题`，标签黑体加粗；正文宋体不加粗 |
| 表注 | 表下方，8 pt 灰色，写清模型/检验、校正方法、缩写、对数转换（†） |
| 表内字号 | 7–8 pt |
| 标点 | 正文用中文全角标点；数字区间用 `～` 或 `–`（如 `0–6 h`、`−6.3～−3.0`）；小数点用半角 `.` |
| 负号 | 图内用 hyphen-minus（`-`，`apply_style` 已设置）；正文中的负数用 `-` 或 `−` 但全文统一 |

## 2. 图内文字词表（中文集）
| 概念 | 中文 | 备注 |
|---|---|---|
| Baseline / Week 12 | 基线 / 第12周（或 12周） | 图内可用 `12周` |
| Control / Intervention | 对照组 / 干预组 | 等待名单对照写"对照组"，图注说明 |
| Mean ± SD / SEM | 均值 ± SD / 均值 ± SEM | SD/SEM 保留英文缩写 |
| Time after start | 干预开始后时间 (h) | 注明 t=0 |
| Change from baseline | 相对基线变化 | 带单位 |
| Difference vs control | 与 CON 的配对差 | |
| Favours | ← 对照组更优 / 干预组更优 → | 森林图 |
| Individual | 个体 | 图注里写"细线为个体" |
| Simulated data | 模拟数据 · Simulated data | `save_figure` 自动添加，右下角 5 pt 灰色斜体 |

坐标轴标签 = **量名 + (单位)**：`血糖 (mmol/L)`、`骨骼肌量 (kg)`、`14 d TIR (%)`、`0–6 h net iAUC (mmol·h/L)`。时间轴写清含义：`钟表时间（t=0 为 09:30）`。单位一律国际单位制拉丁写法，不译成中文。

## 3. 数字与统计格式
- 描述统计 `均值 ± SD`（保留 1–2 位有效小数，|x|<10 取 2 位，<100 取 1 位，其余取整）；分类变量 `n (%)`。
- 估计值 `估计值 (95% CI 下限, 上限)`；正文写作 `-4.3 mmol·h/L（95% CI -6.3～-2.3，P < 0.001）`。
- P 值：`P < 0.001` 或 `P = 0.012`（三位小数，**不写 0.000、不写 P = <0.001**）。表内列只写 `<0.001` / `0.012`。
- 效应量：Hedges g（组间）、配对 d_z（交叉）；写明基于何种变量。
- 多重比较：预设对比用 Holm，次要结局按类别 BH-FDR，主要结局不校正；校正后的概率分别记作 `Holm P`、`BH q`。
- 缺失/排除：说明 CGM 有效数据比例阈值、脱落人数、敏感性分析。

## 4. 图注模板
```
图 N  {一句话标题}。a，{内容}（{误差带含义}）；b，{内容}；c，{内容}。
{统计与符号说明：模型、校正、阴影/误差线的含义、n、缩写。}
```
示例：
```
图 3  主要结局 0–6 h net iAUC。a，每名受试者在各条件的观测（浅色点；细线连接完成四条件者）与线性混合模型估计边际均值 ± 95% CI；
b，条件间差值及 95% CI（RT − CON 的 P 值为 Holm 校正，虚线为预设的 10% 临床阈值）；c，各剂量较 CON 的变化与线性趋势。
```

## 5. 表格模板
```
表 N  {标题}
┌─────────────────────────────────────────┐  ← 粗线（12 sz）
 指标 | 干预组 基线 | 干预组 第12周 | …| 组间差异 (95% CI) | P | BH q
├─────────────────────────────────────────┤  ← 细线（6 sz）
 …（无竖线、无底纹）
└─────────────────────────────────────────┘  ← 粗线
{表注：均值 ± SD。组间差异为…模型…；BH q 为类别内校正；† 为对数转换。}
```
- 表 1（基线）必须有 SMD 与 P；SMD 绝对值 ≥ 0.5 的变量在正文中点名并说明已做基线调整的敏感性分析。
- 列标题含单位或统计量时写在表头或首列行名里，不在单元格里重复。

## 5b. 结果正文句式（中文）
| 场景 | 句式（花括号内由变量填充） |
|---|---|
| 主要结局组间差 | `干预组较对照组多提高 {b:.1f} 个百分点（95% CI {lo:.1f}～{hi:.1f}，{P}，Hedges g = {g:.2f}），{差异具有统计学意义 / 差异未达统计学意义}。` |
| 交叉主效应 | `三个弹力带条件的平均值较 CON 低 {x:.1f} mmol·h/L（95% CI {lo:.1f}～{hi:.1f}，{P}，配对 d_z = {dz:.2f}）。` |
| 校正后多重比较 | `Holm 校正后，RT20（{b:.1f}，Holm {P}）、RT30（…）、RT45（…）均显著低于 CON。` （仅当三个校正 P 均 <0.05 时用"均显著"，否则逐一陈述） |
| 无差异 | `RT20 与 RT45 相差 {d:+.1f}（95% CI {lo:.1f}～{hi:.1f}，{P}），差异未达统计学意义。` — **不写"无差异"代替"未检出差异"** |
| 探索性 | `此类次要结局未做多重比较校正，仅作探索性描述。` |
| 基线不均衡 | `按 |SMD| ≥ 0.5 判断，存在不均衡的变量有 …，后文对主要结局增加了基线调整的敏感性分析。` |
| 安全性 | `两项研究共记录不良事件 {n} 起，严重不良事件 {s} 起，最常见的为 …。` |

## 6. 禁用与易错
- 禁用：整图大标题、3D、彩虹色、饼图、带边框图例、默认灰底网格、荧光绿/正红/正蓝。唯一例外：眼动注视热力图用 `turbo`（领域标准画法），仅是眼动函数的默认值。
- 图内禁止出现英文长句；缩写（TIR、TAR、HbA1c、SD、SEM、CI）可保留。
- 同一对象全篇同一颜色；剂量顺序用有序色带（浅雾蓝→海军蓝）。
- 中文图用于英文稿件前必须改用英文集重新生成，**不能**靠手工翻译标签。

## 7. 按数据类型的作图约定（所有数据类型通用，见 `reference/DATA_TYPE_GUIDE.md`）
- **波形/曲线**（肌电、关节角、GRF、配速）：横轴归一化（% 周期/% 支撑期），均值 ± SEM（或 ± SD，须注明）；两条波形的差异用 SPM{t}（置换检验阈值）而不是逐点 P。
- **单人单值**：配对设计用"原始点 + 连线 + 估计 ± 95% CI"；≥3 组或不配对用 raincloud（密度 + 原始点 + IQR + 均值 ± CI），密度只画观测范围。
- **量表/等级数据**：单题用分层堆叠条（Likert），总分用 raincloud 或多时点均值 ± 95% CI；相关矩阵用下三角，粗体表示 P<0.05；剖面用雷达图；中介分析画路径图并给出间接效应的 bootstrap 区间。
- **生存分析**：KM 曲线带 95% CI 阴影与删失标记，下方"风险集人数"表，HR 森林图用对数轴。
- **诊断/预测**：ROC（AUC 与 bootstrap 95% CI，Youden 点）、校准图；图例放在坐标轴下方，不遮挡曲线。
- **一致性/信度**：恒等线 + ICC(2,1)，Bland–Altman（偏倚与 95% 一致性界限含 CI），ICC 森林图并标注 CV%。
- **荟萃分析**：森林图（方块面积 ∝ 权重，菱形 = 合并），漏斗图，Meta 回归用气泡图。
- **组学**：火山图（上调主色、下调石板蓝），聚类热图带分组色条，PCA 得分图带 95% 椭圆。
- **对数坐标**：坐标刻度写成普通数字（0.5、1、2、4），不要用 10^n；关闭次刻度标签。
- **配色**：Likert 与相关矩阵使用"对比色/雾蓝/主色"发散色（`DIVERGING`，赤陶–纸色–海军蓝）；序列热图用 `SEQ`（纸色→海军蓝）；≥5 个无序类别用 `category_colors(n)`。
