# 运动科学顶刊级作图指南（v4，海军蓝一套，中英文两套语言）
> **配色只有一套：海军蓝。** 色值与角色固定在 `sportsci_figures/pubstyle/style.py`。
> **AI Agent 请从 `SKILL.md` 开始读**；本文只讲设计理由、色板与成图精修规则。

## 一、设计哲学
1. **去杂质化极简边界**：无顶/右边框、刻度朝外、无灰底网格、图例无边框。
2. **克制而有层次的对比色**：海军蓝 + 沙金 + 赤陶，且**角色固定**（见下）。
3. **高信息密度复合图**：`a b c d` 面板由"总体曲线 → 放大 → 差值/估计 → 剂量–反应"咬合。
4. **展示原始数据 + 模型估计 ± 95% CI**：小样本、重复测量设计必须画个体点与连线；估计图取代"柱 + 误差线"。
5. **效应量与不确定性进图**：条件间差值、Hedges g 森林图直接标 95% CI 与精确 P/q；不用星号堆叠。
6. **图与表同源**：图上的估计值与表格来自同一个模型；多重比较方法写进图注/表注。

## 二、色板与语义角色（固定，代码在 `pubstyle/style.py`）
| 角色（代码名） | 色值 | 用法 |
|---|---|---|
| 干预组 / 最高剂量 / 主要结局（`C_PRIMARY`） | **海军蓝** `#112378` | 加粗实线，阴影带 16–20% 透明 |
| 对照组 / 参照条件（`C_CONTROL`） | **沙金** `#C9A66B` | 折线用虚线 |
| "对比"类别 / 有害（`C_CONTRAST`） | **赤陶** `#C4573F` | |
| 中间剂量（`C_MID`） | `#3F4F9E` | 由 `dose_colors(n)` 插值：浅雾蓝 `#9BA5D3` → 海军蓝，亮度单调下降，灰度打印仍可分 |
| 基线访视 / 中性构成 / 参考（`C_SLATE`） | **雾蓝** `#8E98C6` | |
| 第四类别（`C_TEAL`） | 深青 `#2F6F73` | |
| 文本 / 注释 / 个体连线 | 墨色 `#161A26` / `#626778` / `#D5D2CA` | |
连续色阶：纸色 → 海军蓝（`SEQ`）；发散色阶：赤陶 – 纸色 – 海军蓝（`DIVERGING`，相关矩阵、载荷热图用它）。**禁止**：彩虹色、荧光绿、正红/正蓝、默认 matplotlib 循环色、`magma`/`viridis` 等内置色阶。
**唯一的例外：眼动注视热力图**用彩虹类的 `turbo`——这是眼动领域的标准画法，热点必须在照片上看得清。它只是眼动热图函数（`ax_gaze_heatmap` / `fig_gaze_heatmap_grid`）的默认值（常量 `GAZE_CMAP`，可用 `cmap=` 覆盖），不是全局设置；其他所有图（包括画在场地或刺激图上的别的热图）仍然只用海军蓝。
旧代码名 `C_MAGENTA / C_AMBER / C_CORAL` 仍可用，是上述角色的别名（含义是"角色"，色值是蓝 / 沙金 / 赤陶）。

## 三、两套语言（详见 `reference/STYLE_SPEC_ZH.md` / `STYLE_SPEC_EN.md`）
| | 中文集 `apply_style("zh")` | 英文集 `apply_style("en")` |
|---|---|---|
| 图内语言 | 中文标签 + 国际单位 | 全英文，**禁止出现任何汉字**（`save_figure` 会报错） |
| 字体 | Arial（拉丁）+ 微软雅黑/苹方/Noto Sans CJK（汉字，逐字符回退） | Arial |
| 图注/表题 | `图 1  …` / `表 1  …`（学位论文 `图 4-1`） | `Figure 1. …` / `Table 1. …` |
| Word | 宋体 + Times New Roman，标题黑体 | Times New Roman |
**版式、配色、尺寸、统计完全相同。** 字体回退的关键是 `font.family` 写成**列表** `['Arial','Microsoft YaHei']`，不要写 `family='sans-serif'` + 长列表（会让拉丁字符也用中文字体）。

## 四、图的尺寸与字号
单栏 3.5 in（89 mm）/ 双栏 7.2 in（183 mm）；正文 7 pt、刻度 6.5 pt、注释 5.5–6 pt、面板字母 9 pt 粗体；PNG 300 dpi + 矢量 PDF（`pdf.fonttype 42`）。

## 五、图型目录（`sportsci_figures.pubstyle.figures`）
时间过程带 `ax_bands`/`ax_diff_band` · 原始数据 + 估计 `ax_paired_estimate` · 对比森林 `ax_contrast_forest` · 剂量–反应 `ax_dose_response` ·
前后轨迹 `ax_prepost` · 全结局效应量森林 `fig_forest_effects` · 构成条 `ax_stacked_bars` · 日内曲线 `ax_agp` · 散点拟合 `ax_scatter_fit` · 流程图 `draw_flow`。
每种的图片与布局见 `reference/FIGURE_CATALOG.md`；可运行的完整范例见 `examples/pubstyle_demo.py`（同时输出中、英两套）。

## 六、成图精修规则（v4，决定"高级感"）
统计内容不变，下面这些细节让图从"正确"变成"好看"：
* 每个面板 **粗体字母 + 简短标题**（`panel_title`），读者不看图注也知道每块在讲什么；
* 误差线/置信区间一律用**组色**、无端帽，均值点带白边；不要用黑色误差线盖住彩色数据；
* 时间进程画**均值线 + 95% CI 阴影带**，线端直接标组名（自动避让），对照组虚线，不用图例；
* 单个模型对比画成**估计图**（`results.plots.diff_estimate`）：t 抽样分布半小提琴 + 点估计 + 95% CI + 数值，取代只有一行的森林图；
* 云雨图密度平滑收尾并描边，IQR 用细灰线；
* 效应量森林图紧凑化：类别色条、斑马纹行、数值列紧贴坐标轴、"对照/干预更优"置于顶部；
* 长刻度标签自动换行（`wrap_label`），面板宽度按内容分配，`wspace` 约 0.35–0.45。

## 七、避坑清单
* ❌ 默认灰底网格、顶/右边框、带框图例、整图大标题、3D、饼图、彩虹色（眼动注视热力图除外，见上）
* ❌ 黑色误差线压在彩色数据上；只有一行的森林图占整块面板；被截成平头的密度图
* ❌ 英文稿件里出现汉字；用手工翻译中文 PNG 代替重新生成
* ❌ 先画图后 `apply_style`（图会沿用旧字体）
* ❌ 手写结果数字；把 P ≥ 0.05 写成"显著"
* ✅ 面板字母 a b c 粗体小写 + 简短面板标题；直接标注优先于图例
* ✅ 个体数据 + 估计 ± 95% CI；SEM/CI 的含义写明
* ✅ PNG 300 dpi + PDF；模拟数据加"Simulated data"标签

## 八、通用化：26 种数据类型（`examples/gallery/` 与 `reference/DATA_TYPE_GUIDE.md`）
同一套风格覆盖：生理（心肺、HRV、负荷）、神经肌肉与生物力学（肌电、力-时曲线、力-速度、SPM 关节曲线、GRF、IMU、平衡 COP、GPS 追踪）、
运动表现（力量多时点、重测信度、响应者、计时赛、DXA、咖啡因剂量反应）、心理量表（Likert、相关、雷达、中介）、流行病学与诊断（生存、ROC、荟萃分析）、
生物样本（睡眠与可穿戴、生物标志物、组学）以及研究设计（时间线、周期化）。选择规则："按数据的形状选块，风格不变"。
