# 中文 AI 痕迹清单与改写

这份清单是给执行润色任务的 agent 看的。不是审美建议，是硬性约束：润色后的文本里出现以下任何模式，就算没完成任务，必须重改。

每条都给出 **AI 写法 → 人写法** 的对照。模仿对照里的"人写法"。

## 一、标点滥用

### 1.1 破折号"——"做插入语

AI 极偏爱用 `——……——` 或 `……——` 插入补充说明。中文学术写作里这种结构罕见，看到就刺眼。

- ❌ 高强度间歇训练——一种近年广受关注的训练方式——能显著提高 VO2max。
- ✅ 高强度间歇训练近年广受关注，可显著提高 VO2max。
- ✅ 高强度间歇训练能显著提高 VO2max，这一方法近年广受关注。

规则（作者个人禁用项，见 SKILL.md 原则 2）：**正文句子里破折号为 0**。唯一保留的是论文标题里的副标题（"运动与免疫：一项 12 周干预研究"，也可用破折号）。表示范围用波浪号："60%～80%"。其它一律改写成逗号、冒号或两句话。

### 1.2 括号"（…）"做补充说明

AI 写中文时大量用括号塞次要信息，模仿英文的 parenthetical aside。中文论文的括号应该只装：缩写定义、单位、统计量、引文。装"补充解释"的括号要拆掉。

- ❌ 受试者（均为男性大学生）完成了三次测试（每次间隔 48 小时）。
- ✅ 30 名男性大学生完成了三次测试，每次间隔 48 小时。

允许保留的括号示例：
- 最大摄氧量（VO2max）：缩写首次出现
- 心率（次·min⁻¹）：单位
- (P < 0.05)：统计量
- (Smith 等, 2021)：引文

### 1.3 顿号 / 逗号堆砌的"长名词串"

- ❌ 本研究测量了心率、血压、血乳酸、皮质醇、睾酮、肌酸激酶、白细胞计数、IgA 等指标。
- ✅ 本研究测量了心率与血压等心血管指标，乳酸、皮质醇、睾酮、肌酸激酶等代谢与内分泌指标，以及白细胞计数和 IgA 两项免疫指标。

把长串改成有结构的分类。

### 1.4 中英混排空格

中文期刊与学位论文的传统排版习惯：**中英文（或中文与数字、缩写）紧贴，不加空格**。AI 倾向于在中英文之间加半角空格。这是它写英文的习惯延伸到了中文，是显眼的"机器味儿"。

#### 不加空格的情况

| 类型 | 错误 | 正确 |
|---|---|---|
| 中文 + 英文缩写 | AI 助教 / VO2max 提高 | AI助教 / VO2max提高 |
| 中文 + 阿拉伯数字 | 30 名 / 8 周 / 12 周 | 30名 / 8周 / 12周 |
| 中文 + 单字母 | T 检验 / F 值 | T检验 / F值 |
| 作者名 + 等 | Smith 等 / Bilić 等 | Smith等 / Bilić等 |
| 作者名 + 引用号 | Hong 等 [18] | Hong等[18] |
| 全角括号前后 | 本研究 （n=30） 发现 | 本研究（n=30）发现 |
| 全角括号内 | （ t=2.10，P<0.05 ） | （t=2.10，P<0.05） |
| 统计符号前后 | P < 0.05 / r = 0.32 | P<0.05 / r=0.32 |
| 数字 + 中文单位 | 32 % / 6 个月 | 32% / 6个月 |

#### 允许加空格的情况

- 英文短语内部（这是英文本身的规则）：`as described by Smith et al`
- 引文中的英文姓名格式：`Smith JA, Jones BC`
- 物理 SI 单位（按期刊规范，可选）：`12 km` / `12km` 都可

#### 起源说明

加空格的写法（"AI 助教"、"VO2max 提高"）来自现代技术文档（W3C 中文排版指南、"中文文案排版指北"），是 markdown / 代码上下文里的便利约定。**中文期刊与学位论文延续传统紧贴排版**，中英文之间不加空格，因为汉字与拉丁字母在视觉上自然分隔，无需空格辅助。

### 1.5 分号"；"串接长句

分号在中文正文里承担"并列长句"的角色。AI 输出常把本该分开的两三句话用分号粘成一句，一段里还出现好几个，读起来像说明书。

- ❌ 本研究采用随机交叉设计；受试者完成四个条件；每个条件间隔 7 天；主要结局为 0～6 h 净 iAUC。
- ✅ 本研究采用随机交叉设计，受试者完成四个条件，每个条件间隔 7 天。主要结局为 0～6 h 净 iAUC。
- ✅ 本研究采用随机交叉设计，受试者依次完成四个条件，间隔 7 天，主要结局为 0～6 h 净 iAUC。

**规则（作者个人禁用项，见 SKILL.md 原则 2）**：

1. **正文句子里分号为 0**，一律用句号切分。
2. 1）2）3）列举项之间也用句号："存在两个问题：1）未设置对照组。2）很少探究延续效果。"
3. 自检：润色完搜一遍 `；`，括号外出现一个就改一个。检查脚本会逐个报出。

#### 唯一例外：统计量集中报告（这一处的分号要保留）

当多组比较走同一逻辑时，中文期刊的标准写法是把统计量压进一个括号、**用分号分隔**：

- ✅ 男童学习日和双休日 LPA、MVPA 时间均显著高于女童（t=2.10，P<0.05；t=2.45，P<0.05；t=2.3，P<0.05）。
- ✅ 两主效应的作用均显著（F=2.736，P<0.05；F=4.753，P<0.05）。

**这类分号不要抑制**。它在括号内分隔统计量，不属于正文句子。但注意两点：

- 同一段里这种括号不宜出现多个，否则照样显机器味。
- **不要把"正文该分开的句子"伪装成"统计量括号"来逃避本条规则。**

## 二、机械分点词

`首先 / 其次 / 再者 / 此外 / 最后 / 综上所述` 这一套是 AI 体最显眼的特征。学术中文里偶尔用 1–2 个无所谓，**但不能在同一段里凑齐三个以上**，更不能每段开头都用。

### 替换策略

- "首先" → 直接陈述第一个观点，不加引导词
- "其次" → 用具体的逻辑连接（"在此基础上"、"与之相关的是"），或干脆另起一段
- "再者" → 几乎不用，删掉
- "此外" → 仅在引入真正"额外"信息时用一次
- "最后" → "在结果层面"、"就实践意义而言"，或直接陈述
- "综上所述" → "本研究发现"、"上述结果表明"，或直接给结论

### 对照

- ❌ 首先，受试者完成了基线测试。其次，进行了为期 8 周的训练。再者，复测了所有指标。最后，进行了统计分析。
- ✅ 受试者完成基线测试后，进入为期 8 周的训练干预，干预结束后复测全部指标并进行统计分析。

## 三、AI 套词与套句

### 3.1 高频"AI 词"

下列词在严肃中文学术写作里出现频率远低于 AI 输出。能换就换。

| AI 偏爱 | 改写方向 |
|---|---|
| 深入探讨 / 深入研究 | 探讨 / 分析 / 考察 |
| 全面分析 / 全方位 | 分析（删修饰） |
| 至关重要 / 极其重要 | 关键 / 重要 |
| 具有重要意义 / 具有深远意义 | 有助于…… / 可用于…… |
| 不容忽视 | 直接陈述事实 |
| 值得注意的是 | 删掉 |
| 综上所述 | 上述结果表明 / 本研究发现 |
| 与此同时 | 同时（且仅在真正同时发生时用） |
| 在……领域 | 在……研究 / 在……方面 |
| 为……提供了新的视角 | 删掉，或具体说明提供了什么 |
| 助力 / 赋能 | 有助于 / 有利于 |
| 打造 / 构建（用在抽象概念上） | 形成 / 建立 |
| 进一步 + 动词（堆叠时） | 仅在确实"递进"时用一次 |

### 3.2 套句模板

整段套句直接删除或重写：

- ❌ 综上所述，本研究通过深入探讨 X 与 Y 的关系，为该领域提供了新的视角，具有重要的理论与实践意义。
- ✅ 本研究表明 X 与 Y 之间存在 [具体关系]，提示 [具体应用]。

## 四、句法层面的 AI 体

### 4.1 "的的不休"

同一个分句（逗号、分号、冒号之间）里出现 3 个及以上的"的"是危险信号。整句长时总数到 4、5 个很常见，真人期刊长句也会如此，关键看是否集中在一个名词链里。

- ❌ 长期高强度的训练对运动员的心血管系统的适应性的影响是显著的。
- ✅ 长期高强度训练显著影响运动员心血管系统的适应性。

策略：删修饰性的"的"，把名词短语并入动词。把"……是显著的"改成"显著……"。

### 4.2 名词化堆砌（性 / 化 / 度）

- ❌ 训练强度的合理性与训练量的科学性对运动表现的提升度有显著的相关性。
- ✅ 训练强度与训练量是否合理科学，与运动表现提升显著相关。

把"……性"改成形容词或动词。

### 4.3 对仗成癖

AI 喜欢造对称句："不仅……而且……"、"既……又……"、"既要……也要……" 连续使用就显得做作。

- ❌ 该方案不仅提高了运动表现，而且改善了心理状态，既缓解了疲劳，又增强了恢复。
- ✅ 该方案提高了运动表现，改善了心理状态，并加快了疲劳后的恢复。

### 4.4 段落形状："凤头、猪肚、豹尾"

AI 段落典型结构：第一句给出主题（topic sentence），中间扩写，最后一句换种说法把主题再说一遍。读起来像作文。

- 改法：删掉段尾的 restatement 句，让段落自然结束在最后一个新信息上。

### 4.5 「不是……而是……」对照结构

AI 中文极爱用"不是 A，而是 B"来制造转折感。这种句式常常用对比掩盖一个事实：作者真正要说的只有 B。

- ❌ 这不仅是训练时长的问题，而是剂量设计的问题。
- ❌ 差异不是来自训练时长，是来自剂量设计。
- ✅ 差异主要来自剂量设计。
- ❌ 抗阻训练的价值不在于降低当次血糖，而在于改善长期的血糖调控。
- ✅ 抗阻训练对长期血糖调控的作用，比对当次血糖的作用更值得关注。
- ❌ 训练不再是单纯的体能储备，而是比赛表现的基础。
- ✅ 训练为比赛表现提供基础。

规则（作者个人禁用项，见 SKILL.md 原则 2）：**全文 0 次**。以下变体一并禁用：「不只是……而是……」「不仅是……而是……」「不是……，是……」「并非……而是……」「不再是……而是……」「与其说……不如说……」「不在于……而在于……」。改法是直接陈述 B，必要时给出 B 的证据。

不算对照句的情况：单纯的否定陈述，如"受试者不是全部完成了测试"。

## 五、学究化骨架词（高优先级）

AI 中文最隐蔽也最高频的一种 tell：**用抽象名词搭骨架来回避具体动词**。这类词单独看似乎正常，但堆叠出现就让全文虚浮。它们的特征是"X 的 Y"、"X 层面"、"X 维度"、"X 框架"、"X 证据"——其中 X 和 Y 都是抽象概念，整句话翻译成"某个东西的某个方面有某种状况"，没有具体动作。

### 5.1 名词支架替换为动词

| AI 骨架 | 改写方向 |
|---|---|
| 解读框架 / 分析框架 / 理论框架（无具体所指时） | 应用方法 / 具体机制 / 操作流程 |
| X 学层面 / X 维度 / X 视角下 | 在 X 中 / 就 X 而言（或直接删，把动作前置） |
| 不确定性 / 复杂性 / 多样性（作主语时） | 不稳定 / 复杂 / 多样（改回形容词或动词） |
| 应用证据 / 实证证据 / 经验证据 | 研究 / 报道 / 数据 / 现状 |
| 议题 / 范畴 / 范式 | 问题 / 类别 / 做法 |
| ……同样突出 / 同样值得关注 | 也存在 …… / 也有 …… |
| 走在 …… 之前，带来了 …… | …… 面临 …… |
| 呈现出 …… 的态势 / 趋势 | 正在 …… / 越来越 …… |
| 在 …… 背景下 | 因为 …… / 鉴于 ……（或删） |
| 从 …… 视角出发 | 用 …… 方法 / 围绕 ……（或删） |

### 5.2 对照示例

- ❌ 然而 CGM 在运动员人群中的**解读框架**仍未达成共识。
- ✅ 然而 CGM 在运动员人群中的**应用方法与具体机制**仍未达成共识。

- ❌ **测量学层面的不确定性同样突出**。
- ✅ **应用场景中还存在测量稳定性问题**。

- ❌ 商业化推广**走在科研之前，带来了新的伦理与方法学议题**。
- ✅ 商业化推广**面临伦理与方法争议**。

- ❌ 本综述梳理 CGM 在运动员人群中的**应用证据**。
- ✅ 本综述梳理 CGM 在运动员训练与比赛中的**研究现状**。

- ❌ 用 CGM **预测过度训练或赛中"撞墙"**。
- ✅ 用 CGM **识别过度训练征兆或比赛末段的低血糖事件**。

### 5.3 自检方法

读完一段后挑出所有抽象名词作主语或宾语的句子，问自己："这里的真实动作是什么？"如果能用一个具体动词替代名词支架，就替代。例：

- "存在着 X 的不确定性" → "X 不稳定"
- "X 层面的研究尚不充分" → "对 X 的研究尚不充分"
- "在 X 背景下，Y 显得尤为重要" → "因为 X，所以 Y 关键"（或干脆删掉前半句）

## 六、语气与立场

### 6.1 过度赞美自己的研究

- ❌ 本研究首次系统地探讨了……，填补了该领域的空白。
- ✅ 本研究在 [具体方面] 扩展了既往工作 [引文]。

"首次"、"填补空白"、"重要突破"、"开创性" 这类表述除非确有其事且能引证，否则一律删除。审稿人极反感。

### 6.2 过度对冲

- ❌ 本研究的结果可能在一定程度上提示，X 或许与 Y 存在某种潜在的关联。
- ✅ 本研究结果提示 X 与 Y 相关。

中文学术写作的对冲应该来自数据本身（"P = 0.06，趋势性显著"），而不是来自措辞的层层包裹。

## 七、对话残留与编辑痕迹（最容易穿帮的一类）

这一类的共同特征：句子本身语法没问题，但它**属于"写作过程"**，是跟 AI、跟导师、跟合作者沟通时留下的话，或者改稿时的临时标记。审阅者看到第一反应是"这是什么"，第二反应是"这是 AI 写的吧"。

### 7.1 第二人称与指示读者

- ❌ 你需要先确认基线血糖是否稳定。
- ❌ 下面我们介绍 CGM 数据的处理流程。
- ❌ 需要注意的是，本研究的样本量偏小。
- ✅ 基线血糖的稳定性需在纳入时确认。
- ✅ CGM 数据处理流程如下。
- ✅ 本研究样本量偏小。（直接陈述，或写进局限段）

命中词：你 / 您 / 咱们 / 请看 / 见下文 / 下面我们 / 需要注意的是 / 值得关注的是

### 7.2 口语与日常表达

- ❌ 其实 20 min 已经差不多够了。
- ❌ 说白了，就是运动量不够。
- ❌ 这个方案挺靠谱，搞定成本问题。

命中词：其实 / 说白了 / 搞定 / 挺 / 差不多 / 有点 / 一块儿 / 拿去 / 弄

### 7.3 第一人称叙事与角色词

论文里唯一合法的"第一人称"是**无主语的被动，或"本研究"**。

- ❌ 我们组前期的研究发现……
- ❌ 我认为该剂量更适合老年人。
- ❌ 课题组已完成预实验。
- ❌ 笔者推测这与胰岛素敏感性有关。
- ✅ 本研究前期研究发现……
- ✅ 该剂量可能更适合老年人。（加引证，或把"认为"改为"提示"）
- ✅ 预实验已完成。（或直接写进正式的方法学描述）

命中词：我们 / 我们组 / 课题组 / 本研究团队 / 团队 / 我认为 / 笔者 / 本人 / 作者认为

⚠️ **"课题组"是最高危的一个**。论文一旦改变作者归属，这个词立刻穿帮，**全文必须 0 次**。同理，写经费来源时不要写"由既有课题经费承担"（会引来"哪个课题"的追问），写"由现有科研经费、实验室或合作医院承担"。

### 7.4 内部讨论话术

把"还没定的事"或"跟谁商量"写进了公开文档。

- ❌ 若结果不支持，或经导师复核后调整研究二方案。
- ❌ 具体剂量待与导师商定后确定。
- ❌ 预算按医院报价再议。
- ✅ 若结果不支持，研究二改为报告可行性、依从性与安全性，并按实际决策如实报告。
- ✅ 剂量按 4.6.2 的预设规则确定。

命中词：经导师 / 与导师 / 待商定 / 再议 / 待讨论 / 后续沟通 / 视情况

### 7.5 编辑痕迹与占位符

改稿过程中的临时标记，忘了删就会真的印在打印稿上。

| 痕迹 | 处理 |
|---|---|
| 待补 / 待定 / TODO / TBD / 略 / 同上 | 补全或删段 |
| XXX / 【】/ □□ / ?? | 补全 |
| 上一版 / 初稿 / 本版 / 修改后（指代版次时） | 删 |
| **孤立的标点段**（整段只有一个"。"或"."） | **整段删除**。它常在文献表域**之外**，Zotero Refresh 也清不掉，会真的印在 PDF 上 |
| 段末缺句号 | 补 |
| 同一句话在一段里出现两次 | 删一处 |

### 7.6 自检方法

对全文跑一遍关键词表（**含表格单元格、图题、页眉页脚**，不能只扫正文段落）：

```
你 您 咱们 请看 下面我们 需要注意的是 值得关注的是
其实 说白了 搞定 挺 差不多
我们 我们组 课题组 本研究团队 我认为 笔者 本人
经导师 待商定 再议 待讨论
待补 待定 TODO TBD XXX 【 】 □□ 上一版 初稿
```

再单独跑三项结构检查：

1. 有没有整段只有一个标点的段落？
2. 有没有段末缺句号？
3. 括号、引号是否全部配对？

⚠️ **词表必然有假阳性，命中后必须看上下文再判断。** 常见假阳性：

- "略低于 15 次"："略"是副词，不是占位符
- "按需转诊"："需"不是"待"
- "自我报告"：含"我"，但是心理学术语
- "挺举"：举重术语，所以检查脚本不收"挺"
- 期刊名里的 `&` 与各种缩写
- "带教团队"、"研究团队"：方法学描述，不是角色词（"我们组"是）

## 八、最终自查（润色后必跑一遍）

完成润色后，对自己的输出过一遍下面的检查：

1. 正文句子里有没有破折号"——"？有 → 改。（§1.1，全文 0 次）
2. 括号里装的是"补充说明"还是"缩写/单位/引文/统计量"？前者 → 拆。
3. 同段内或全文反复出现"首先/其次/再者/最后/综上所述"？→ 删并重写连接。
4. 出现了第三节的 AI 词表里的词？→ 替换。
5. 任何一个分句里"的"达到 3 个？→ 重构。
6. 段尾是否在"换种说法重复段首"？→ 删段尾。
7. 是否有"不仅…而且…"或"既…又…"在同段内出现两次？→ 改一处。
8. 有没有"首次/填补空白/开创性"且没有引证支撑？→ 删。
9. 是否出现第五节的骨架词（解读框架 / X 层面 / 应用证据 / 议题 / 同样突出 / 走在……之前）？→ 用动词重写。
10. 正文句子里有没有分号（统计量括号内的除外）？有 → 用句号切分。（§1.5，全文 0 次）
11. 有没有「不是……而是……」及其变体？有 → 改写。（§4.5，全文 0 次）
12. 有没有对话残留（第七节）？第二人称 / 指示读者 / 口语 / 我们组 / 课题组 / 经导师 / 待补 / TODO？→ **必须为 0**。
13. 有没有整段只有一个标点的段落、或段末缺句号？→ 删掉 / 补上。（§7.5）

跑完仍有命中 → 再改一轮。
