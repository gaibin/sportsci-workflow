# 交付 Word 稿件前的细节：数字、空格、字体、字号与行距

读者打开一份 Word 稿件，最先看到的不是论证，而是数字怎么写、标题怎么排、图表怎么放。程序生成的文档在这些地方有固定的痕迹：数字中间夹空格、"表 1  样本构成"式的双空格、图片下面多出半页空白、宽表首列被压成一字一行。任何 .docx 在交给用户、导师或期刊之前，都按本文件处理一遍。

文档属性（作者、创建和修改时间等）属于个人设置，不在本规范内。本地如需统一处理，放一个不进 git 的 `scripts/docx_metadata.local.py`，`docx_finalize.py` 发现后会在排版之后调用它。

脚本：`scripts/docx_finalize.py`（规则与本文件一致）。

```
python scripts/docx_finalize.py 稿件.docx                          # 原地修改
python scripts/docx_finalize.py 稿件.docx -o 定稿.docx              # 另存
python scripts/docx_finalize.py 稿件.docx --check                  # 只报告问题
python scripts/docx_finalize.py 说明.md                             # 文本文件只做文字修正
```

## 一、数字

| 场合 | 规则 | 例 |
|---|---|---|
| 中文正文，四位数 | 不分节 | 6045名，1000米 |
| 中文正文，五位及以上 | 千分撇（逗号），不用空格 | 33,987人次，241,710名 |
| 英文段落（英文摘要、英文参考文献） | 1,000 起用逗号 | 6,045 students |
| 年份、页码、编号 | 一律不分节 | 2025年，pp. 1166-1169 |
| 数值范围 | 中文用"～"或"至"，英文用不带空格的 en dash | 2.57～3.89，2.57–3.89 |
| 负数 | 同一文档内统一用一种负号，表格与正文一致 | -0.36 |

依据：GB/T 15835-2011 允许千分空和千分撇两种分节方式，四位数可不分节。千分空在 Word 里看起来像打错的空格，用户和审稿人都会误读，所以默认用千分撇。期刊样稿明确要求千分空时再改。

## 二、空格

中文期刊延续传统紧贴排版（另见 `ai-traces-zh.md` §1.4）。

| 位置 | 规则 |
|---|---|
| 汉字与英文字母、数字之间 | 不加空格：30名，VO2max提高，P<0.001 |
| 全角标点前后 | 不加空格 |
| 中文句中的统计符号 | 不加空格：P<0.05，r=0.32 |
| 数字与单位 | 物理单位按期刊样稿，常见为留一个空格：1000 m，12.9 s，15 kg |
| 图表题 | "表1　表名"，表序不拆开，表序与表名之间空一个汉字（全角空格） |
| 层次标题 | "2.1　标题"，序码后空一个汉字，不加点号（《体育学刊》要求） |
| 双空格 | 全文为 0 |
| 英文段落 | 英文本身的规则：单词间一个空格，P < 0.05 两侧留空 |

## 三、字体、字号与行距

期刊没有规定时用下表。依据：《北京体育大学学报》投稿须知要求"题目小三黑、正文小四宋、参考文献小四宋、全文英文 Times New Roman、全文 1.5 倍行距"。《体育学刊》2023 年版投稿指南未规定字体字号，只规定表格三线表、图题在图下居中、表题在表上居中。投稿前先读目标期刊须知，有规定以期刊为准。

| 元素 | 字体 | 字号 | 行距与段落 |
|---|---|---|---|
| 题目 | 黑体 | 小三（15 pt）加粗 | 居中 |
| 一级标题（1　……） | 黑体 | 四号（14 pt） | 段前 12 pt，段后 6 pt |
| 二级标题（1.1　……） | 黑体 | 小四（12 pt） | 段前 6 pt |
| 三级标题（1.1.1　……） | 宋体加粗 | 小四 | 段前 6 pt |
| 正文、摘要、关键词 | 宋体，英文和数字 Times New Roman | 小四（12 pt） | 1.5 倍行距，首行缩进 2 字符（摘要、关键词不缩进） |
| 英文题目 | Times New Roman 加粗 | 小四 | 居中，不缩进 |
| 图所在段落 | / | / | **单倍行距**，居中，不缩进 |
| 图题、表题 | 宋体，表序图序加粗 | 五号（10.5 pt） | 单倍行距，居中，表题在表上，图题在图下 |
| 表格内文字 | 宋体 / Times New Roman | 五号，6 列及以上用小五（9 pt） | 单倍行距，列宽按内容自适应 |
| 表注 | 宋体 | 小五 | 单倍行距 |
| 参考文献 | 宋体 / Times New Roman | 小四 | 1.5 倍行距，不缩进 |

**图片行距**：图片段落如果沿用正文的 1.5 倍行距，Word 会把整行按 1.5 倍放大，图下出现半张图高的空白。正文若用"固定值"行距，嵌入式图片会被截掉上半部分。所以图片段落一律单倍行距。

**宽表**：固定列宽会把首列压窄，每个标签折成三四行。表格宽度设为页宽 100%，列宽交给 Word 按内容分配。

## 四、交付前自检

1. 跑 `docx_finalize.py --check`，结果为 clean。
2. 用 Word 打开或导出 PDF 看两三页：题目、一级标题、一个图、一个宽表、参考文献各看一眼。
3. 匿名稿：正文没有校名、人名、基金号。

## 五、英文稿的对应规则

| 项目 | 规则 |
|---|---|
| 数字 | 1,000 起用逗号，数字与单位之间用不换行空格（12 km） |
| 范围 | en dash 不带空格（weeks 1–4），文中不用破折号作插入语（见 SKILL.md 原则 2） |
| 统计符号 | 斜体 P、t、F、r，运算符两侧留空（P < 0.05），按期刊决定是否保留前导零 |
| 字体 | Times New Roman 12 pt，双倍或 1.5 倍行距按期刊须知，期刊无规定时英文稿默认双倍行距并加行号 |
